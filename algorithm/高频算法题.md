## 01 反转链表

**题目：** 反转单向链表。

**思路：** 迭代法，三指针逐步反转。

```python
def reverseList(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev, cur = cur, nxt
    return prev
```

**复杂度：** 时间 O(n)，空间 O(1)

**变体：** 反转链表 [m, n] 区间

## 02 层序遍历

**题目：** 二叉树层序遍历，按层输出。

**思路：** BFS + 队列，记录每层节点数。

```python
from collections import deque

def levelOrder(root):
    if not root: return []
    result = []
    q = deque([root])
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        result.append(level)
    return result
```

**复杂度：** 时间 O(n)，空间 O(n)

## 03 LIS

**题目：** 最长递增子序列的长度。

**思路 1：** DP, O(n²)
```python
def lengthOfLIS(nums):
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

**思路 2：** Patience sorting + 二分, O(n log n)
```python
import bisect
def lengthOfLIS(nums):
    tails = []
    for x in nums:
        i = bisect.bisect_left(tails, x)
        if i == len(tails): tails.append(x)
        else: tails[i] = x
    return len(tails)
```

## 04 两数之和

**题目：** 数组中找两个数，使其和为 target。

```python
def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```

**复杂度：** 时间 O(n)，空间 O(n)

## 05 合并K个链表

**题目：** 合并 K 个有序链表。

**思路：** 最小堆。

```python
import heapq
def mergeKLists(lists):
    heap = []
    for i, node in enumerate(lists):
        if node:

    while heap:

```

**复杂度：** 时间 O(N log K)，空间 O(K)

## 06 LRU

**题目：** 实现 O(1) 的 LRU 缓存。

**思路：** HashMap + 双向链表。

```python
class Node:
    def __init__(self, key=0, val=0):
        self.key, self.val = key, val
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.cache = {}
        self.head, self.tail = Node(), Node()
        self.head.next, self.tail.prev = self.tail, self.head

    def remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def add_to_head(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def get(self, key):
        if key not in self.cache: return -1
        node = self.cache[key]
        self.remove(node)
        self.add_to_head(node)
        return node.val

    def put(self, key, value):
        if key in self.cache:
            node = self.cache[key]
            node.val = value
            self.remove(node)
        else:
            node = Node(key, value)
            self.cache[key] = node
            if len(self.cache) > self.cap:
                lru = self.tail.prev
                self.remove(lru)
                del self.cache[lru.key]
        self.add_to_head(node)
```

**复杂度：** get/put 均 O(1)

## 07 快排/TopK

**题目：** 找数组中第 K 大的元素。

```python
import random
def findKthLargest(nums, k):
    def partition(l, r):
        pivot = nums[random.randint(l, r)]
        while l <= r:
            while nums[l] > pivot: l += 1
            while nums[r] < pivot: r -= 1
            if l <= r:
                nums[l], nums[r] = nums[r], nums[l]
                l, r = l + 1, r - 1
        return l
    l, r = 0, len(nums) - 1
    k = k - 1  # 0-indexed
    while True:
        p = partition(l, r)
        if p == k: return nums[p]
        elif p < k: l = p + 1
        else: r = p - 1
```

**平均复杂度：** O(n)，最坏 O(n²)

## 08 岛屿数量

**题目：** 统计网格中的岛屿数量。

```python
def numIslands(grid):
    if not grid: return 0
    m, n = len(grid), len(grid[0])
    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                count += 1
                # BFS flood fill
                from collections import deque
                q = deque([(i, j)])
                grid[i][j] = '0'
                while q:
                    x, y = q.popleft()
                    for dx, dy in [(0,1),(0,-1),(1,0),(-1,0)]:
                        nx, ny = x+dx, y+dy
                        if 0<=nx<m and 0<=ny<n and grid[nx][ny]=='1':
                            grid[nx][ny] = '0'
                            q.append((nx, ny))
    return count
```

**复杂度：** 时间 O(m×n)，空间 O(m×n)
