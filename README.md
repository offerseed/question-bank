# 🧠 题型题库 · Question Bank

## 📂 目录结构

- `machine-learning/` 机器学习基础
- `deep-learning/` 深度学习与神经网络

## 📚 ARIS 精选面试题库

本仓库还收录了来自 **[ARIS-in-AI-Offer](https://github.com/wanshuiyin/ARIS-in-AI-Offer)** 的 34 篇双语面试 cheat sheet，每篇包含 25 道高频题（L1 必会 / L2 进阶 / L3 顶级 lab），附公式推导与详细答案。

| 深度学习 | 16 | Attention、Transformer、归一化、优化器、扩散模型、Flow Matching、VLM、3D生成、世界模型等 |
| 大语言模型 | 18 | RLHF/DPO、LoRA、RAG、KV Cache、MoE、量化、推理服务、Agent、长上下文等 |

## 🚀 如何使用

1. 按知识领域进入对应文件夹。
2. 阅读题目、参考答案与解析。
3. ARIS 系列题目按 L1/L2/L3 难度分层，建议从 L1 开始。
4. 遇到好题，欢迎提交 PR 补充。
