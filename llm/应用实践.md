## 07 RAG

**Q：设计一个 RAG 系统，整体流程是什么？有哪些优化点？**

**参考答案：**

**基本流程：**
1. **文档预处理**：加载 → 分块 → embedding → 存入向量数据库
2. **检索阶段**：query embedding → 向量相似度搜索 → top-k chunk
3. **生成阶段**：query + retrieved context → LLM → answer

**优化点：**

| 环节 | 优化方法 |
| :--- | :--- |
| 分块 | 语义分块、滑动窗口、父子文档 |
| Embedding | 多语言模型、指令微调 embedding |
| 检索 | 混合检索（向量+BM25）、重排序（rerank） |
| 生成 | Context compression、prompt 工程 |
| 评估 | Faithfulness、Relevance 指标 |

**进阶：**
- **Query 改写**：多查询改写、子查询分解
- **Self-RAG**：模型自主判断是否需要检索
- **Graph RAG**：结合知识图谱
- **Multi-modal RAG**：支持图片/表格

## 08 Agent

**Q：什么是 AI Agent？Agent 的核心架构是什么？**

**参考答案：**

**Agent = LLM + 感知 + 规划 + 记忆 + 工具调用**

**核心组件：**

| 组件 | 功能 | 实现 |
| :--- | :--- | :--- |
| LLM | 大脑/推理 | GPT-4, Claude, Qwen |
| Planning | 任务分解 | ReAct, Plan-and-Execute, ToT |
| Memory | 记忆 | 短期（context）/ 长期（向量DB） |
| Tools | 行动能力 | Function calling, MCP |
| Reflection | 自我纠错 | Reflexion, self-evaluation |

**主流框架：**

| 框架 | 特点 |
| :--- | :--- |
| LangChain/LangGraph | 通用，生态丰富 |
| AutoGPT | 自主决策 |
| MetaGPT | 多 Agent 协作 |
| CrewAI | 角色分工 |
| Dify | 低代码 + 可视化 |

**关键挑战：**
1. 长程任务规划能力
2. 工具调用的可靠性
3. 上下文窗口管理
4. 幻觉控制
5. 多 Agent 通信效率

**延伸思考：**
- Agent 和 Workflow 的本质区别是什么？
- 如何评估 Agent 的效果？
