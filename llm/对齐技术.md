## 03 RLHF / DPO

**Q：RLHF 和 DPO 的区别？各自的优缺点？**

**参考答案：**

**RLHF（Reinforcement Learning from Human Feedback）三阶段：**
1. SFT 模型训练
2. 训练 Reward Model（学习人类偏好排序）
3. 用 PPO 优化策略模型，最大化 reward，同时 KL 约束防止偏离 SFT

**DPO（Direct Preference Optimization）：**
直接用偏好数据优化模型，跳过显式 Reward Model 和 RL：
Loss = -log[σ(β·(log π(y_w)/π_ref(y_w) - log π(y_l)/π_ref(y_l)))]

**对比：**

| | RLHF (PPO) | DPO |
| :--- | :--- | :--- |
| 需要 RM | 是 | 否 |
| 训练稳定性 | 差（RL） | 好（分类损失） |
| 计算开销 | 大（4个模型） | 小（2个模型） |
| 效果上限 | 更高 | 接近 |
| 实现复杂度 | 高 | 低 |
| 探索能力 | 有 | 无 |
