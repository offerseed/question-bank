## 01 预训练

**Q：GPT 的预训练任务是什么？为什么选择自回归？**

**参考答案：**

**预训练任务：因果语言建模（Causal Language Modeling）**
给定 token 序列 w_1, w_2, ..., w_t，预测 w_{t+1}：
P(w_{t+1} | w_1, ..., w_t) = softmax(Wh_{t})

**为什么自回归而非 Masked LM（BERT）：**
1. 生成任务天然适合自回归
2. 自回归可以用完整上下文（单向），生成质量更高
3. Scaling Law 在自回归模型上表现更好

**预训练阶段：**
| 阶段 | 目标 | 数据 |
| :--- | :--- | :--- |
| Pretrain | Next token prediction | 大规模无标注文本 |
| SFT | 指令跟随 | 高质量对话数据 |
| RLHF/DPO | 人类偏好对齐 | 偏好数据 |

## 02 LoRA

**Q：LoRA 的原理是什么？为什么它能减少参数量？**

**参考答案：**

**LoRA（Low-Rank Adaptation）核心思想：**
权重更新 W' = W + ΔW，其中 ΔW = A·B（低秩分解）
- A: d×r，B: r×d，r << d
- 冻结原始 W，只训练 A 和 B
- 参数量从 d² 降为 2dr

**优势：**
| 方面 | 全量微调 | LoRA |
| :--- | :--- | :--- |
| 参数量 | 100% | 0.1%-1% |
| 显存 | 高 | 低 |
| 多任务 | 需多份模型 | 只存多份 adapter |
| 效果 | 最优 | 接近全量 |

**QLoRA：**
在 LoRA 基础上，将原模型量化为 4-bit（NF4），进一步降低显存需求，使得单卡可微调大模型。

- 为什么 LoRA 通常只加在 Attention 的 Q/V 上？
