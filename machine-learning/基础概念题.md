## 01 过拟合和欠拟合

**Q：什么是过拟合和欠拟合？如何判断和解决？**

**参考答案：**

| | 过拟合 | 欠拟合 |
| :--- | :--- | :--- |
| 表现 | 训练集误差低，验证/测试误差高 | 训练集和测试集误差都高 |
| 原因 | 模型太复杂、数据太少、训练太久 | 模型太简单、特征不足 |
| 解决 | 正则化、Dropout、数据增强、早停、减小模型 | 增加模型复杂度、增加特征、训练更久 |

**延伸思考：**
- 如何画 learning curve 来判断？
- Dropout 在训练和推理时有什么区别？

## 02 L1 和 L2 正则化

**Q：L1 和 L2 正则化的区别？为什么 L1 会产生稀疏解？**

**参考答案：**

| | L1 正则化 | L2 正则化 |
| :--- | :--- | :--- |
| 公式 | λ∑\|w\| | λ∑w² |
| 几何约束 | 菱形约束 | 圆形约束 |
| 解的特性 | 稀疏（部分权重为 0） | 小但不为 0 |
| 适用场景 | 特征选择 | 防止过拟合 |

**为什么 L1 稀疏：**
L1 的约束区域是菱形，最优解更容易出现在顶点（坐标轴上），即某些维度为 0。L2 的约束区域是圆，最优解通常在各维度都有非零值。

**延伸思考：**
- Elastic Net（L1+L2）有什么优势？
- 正则化系数 λ 怎么选？

## 03 梯度下降法

**Q：梯度下降有哪些变体？它们各有什么特点？**

**参考答案：**

| 方法 | 特点 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| BGD | 全量数据计算梯度 | 稳定 | 慢、内存大 |
| SGD | 每次一个样本 | 快、可跳出局部最优 | 方差大 |
| Mini-batch GD | 小批量 | 平衡速度和稳定性 | 需调 batch size |
| Momentum | 累积历史梯度 | 加速收敛 | 可能过冲 |
| Adam | 自适应学习率 + 动量 | 收敛快、常用 | 可能不收敛到最优 |

**延伸思考：**
- Adam 为什么有时不如 SGD 泛化？
- Warmup 策略的作用？

## 04 偏差-方差分解

**Q：解释偏差-方差分解，以及它们的权衡关系。**

**参考答案：**

总误差 = 偏差² + 方差 + 不可约误差

| | 高偏差 | 高方差 |
| :--- | :--- | :--- |
| 表现 | 训练误差和测试误差都高 | 训练误差低，测试误差高 |
| 对应 | 欠拟合 | 过拟合 |
| 解决 | 增加模型复杂度 | 增加数据、正则化、降低模型复杂度 |

**Bagging 降低方差，Boosting 降低偏差。**

**延伸思考：**
- 为什么集成学习能降低方差？
- 深度学习中的偏差-方差如何理解？

## 05 评估指标

**Q：解释 Precision、Recall、F1、AUC 的含义和适用场景。**

**参考答案：**

| 指标 | 公式 | 含义 | 适用场景 |
| :--- | :--- | :--- | :--- |
| Precision | TP/(TP+FP) | 预测为正中真正为正的比例 | 关注误报（垃圾邮件） |
| Recall | TP/(TP+FN) | 真正为正中被找出的比例 | 关注漏报（疾病检测） |
| F1 | 2·P·R/(P+R) | P 和 R 的调和平均 | 需要平衡 P 和 R |
| AUC | ROC 曲线下面积 | 排序能力 | 不关心阈值，关注排序 |

**延伸思考：**
- 为什么 AUC 对类别不平衡不敏感？
- PR 曲线和 ROC 曲线什么情况下选哪个？

## 06 交叉验证

**Q：常见的交叉验证方法有哪些？**

**参考答案：**

| 方法 | 描述 | 适用场景 |
| :--- | :--- | :--- |
| K-Fold | 分 K 份，每次用 K-1 训练 1 份验证 | 通用 |
| Stratified K-Fold | 每份保持类别比例 | 类别不平衡 |
| Leave-One-Out | 每次留一个样本验证 | 数据量极少 |
| Time Series CV | 用过去数据训练，未来数据验证 | 时间序列 |

**延伸思考：**
- K 的选择对结果有什么影响？
- 交叉验证和网格搜索如何结合？
