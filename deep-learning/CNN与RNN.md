## 01 CNN

**Q：CNN 的基本结构是什么？有哪些经典网络？**

**参考答案：**

CNN 核心组件：
- **卷积层**：局部感受野，权值共享
- **池化层**：下采样，减少参数，增加平移不变性
- **全连接层**：特征整合，输出分类

经典网络演进：

| 网络 | 年份 | 贡献 |
| :--- | :---: | :--- |
| LeNet | 1998 | 最早的 CNN |
| AlexNet | 2012 | ReLU + Dropout + GPU |
| VGG | 2014 | 小卷积核堆叠 |
| ResNet | 2015 | 残差连接，解决退化 |
| Inception | 2014 | 多尺度并行卷积 |
| EfficientNet | 2019 | 复合缩放 |

- ResNet 为什么能训练很深的网络？

## 02 RNN / LSTM

**Q：RNN 的问题是什么？LSTM 如何解决？**

**参考答案：**

**RNN 问题：**
- 梯度消失/爆炸（梯度在时间维度上连乘）
- 长期依赖问题（无法记住远距离信息）

**LSTM 解决方案：**
引入三个门控机制：

| 门 | 作用 | 公式 |
| :--- | :--- | :--- |
| 遗忘门 | 决定保留多少历史信息 | f = σ(W_f·[h_{t-1}, x_t]) |
| 输入门 | 决定写入多少新信息 | i = σ(W_i·[h_{t-1}, x_t]) |
| 输出门 | 决定输出多少信息 | o = σ(W_o·[h_{t-1}, x_t]) |

**核心改进：** 引入 cell state C_t，通过加法而非乘法更新，使梯度能长距离传播。
