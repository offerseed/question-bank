## 05 归一化

**Q：BatchNorm 和 LayerNorm 的区别？为什么 NLP 用 LayerNorm？**

**参考答案：**

| | BatchNorm | LayerNorm |
| :--- | :--- | :--- |
| 归一化维度 | batch 维度 | 特征维度 |
| 计算方式 | 跨样本统计均值方差 | 单样本内统计 |
| 训练/推理 | 需要 running mean/var | 训练推理一致 |
| 依赖 batch | 是 | 否 |
| 适用 | CNN（图像） | RNN/Transformer（序列） |

**为什么 NLP 用 LayerNorm：**
1. 序列长度可变，BatchNorm 受 padding 影响
2. batch 内不同序列长度不同，跨样本统计不合理
3. LayerNorm 对每个 token 独立归一化，不依赖 batch

- 为什么 LayerNorm 通常放在残差连接之后？

## 06 激活函数

**Q：常见激活函数有哪些？各有什么优缺点？**

**参考答案：**

| 激活函数 | 公式 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| Sigmoid | 1/(1+e^-x) | 输出 0-1，平滑 | 梯度消失、非零中心 |
| Tanh | (e^x-e^-x)/(e^x+e^-x) | 零中心化 | 梯度消失 |
| ReLU | max(0,x) | 计算简单、不饱和 | Dead ReLU |
| Leaky ReLU | max(αx,x) | 解决 Dead ReLU | 需调 α |
| GELU | x·Φ(x) | 平滑、BERT用 | 计算稍复杂 |
| SwiGLU | SiLU(x)*W | LLaMA用 | 参数翻倍 |

**延伸思考：**

- GELU 相比 ReLU 的优势在哪？

## 07 优化器

**Q：SGD 和 Adam 的区别？什么时候用哪个？**

**参考答案：**

| | SGD+Momentum | Adam |
| :--- | :--- | :--- |
| 学习率 | 全局/手动调度 | 自适应（每个参数） |
| 动量 | 有 | 有（一阶矩） |
| 二阶信息 | 无 | 有（二阶矩） |
| 收敛速度 | 慢 | 快 |
| 泛化能力 | 通常更好 | 可能稍差 |
| 调参难度 | 需要调 lr schedule | 默认参数可用 |

**经验：**
- 训练大模型（Transformer）常用 AdamW（解耦权重衰减的 Adam）
- 研究/学术有时用 SGD+Momentum 获得更好泛化
- Warmup + Cosine Decay 是主流 lr schedule

## 08 梯度问题

**Q：什么是梯度消失和梯度爆炸？如何解决？**

**参考答案：**

**原因：** 深层网络中梯度通过链式法则连乘，激活函数导数 < 1 会消失，> 1 会爆炸。

**解决方案：**

| 方法 | 解决 | 原理 |
| :--- | :--- | :--- |
| ReLU 激活 | 消失 | 导数为 0 或 1 |
| 残差连接 | 消失 | 梯度可直接传播 |
| BatchNorm/LayerNorm | 消失 | 减小梯度连乘的缩放 |
| 梯度裁剪 | 爆炸 | 限制梯度范数 |
| 合理初始化 | 两者 | Xavier/He 初始化 |

- 为什么残差连接能解决退化问题？
- 为什么 Xavier 初始化对 Tanh 有效，He 初始化对 ReLU 有效？
