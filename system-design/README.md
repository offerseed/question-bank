## 答题框架

系统设计题建议按以下框架回答：

1. **明确需求**（2-3分钟）— 功能需求 + 非功能需求
2. **容量估算**（2-3分钟）— QPS、存储、带宽
3. **高层设计**（5-8分钟）— 核心组件 + 数据流
4. **详细设计**（10-15分钟）— 存储方案、API、算法
5. **扩展优化**（5-8分钟）— 缓存、分片、容灾
