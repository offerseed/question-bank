## 02 短链系统

**Q：设计一个短链系统（如 bit.ly）。**

**参考答案：**

### 需求分析
- 功能：长 URL → 短 URL，短 URL → 长URL 跳转
- 容量估算：100M 条/月，10:1 读写比

### 核心设计

**发号方案：**

| 方案 | 原理 | 优缺点 |
| :--- | :--- | :--- |
| Hash | MD5/MurmurHash + 截断 | 可能冲突，需查重 |
| 自增 ID + Base62 | 全局 ID → 62 进制 | 简单可靠，可预测 |
| 预生成 | 提前生成存 K-V | 无冲突，需维护池 |

**存储：** MySQL 存映射（短码 → 长URL），加 Redis 缓存

**跳转：** 301（永久，可缓存）vs 302（临时，可统计）

## 03 消息队列

**Q：设计一个消息队列（如 Kafka）。**

**参考答案：**

### 核心概念
- Topic → Partition → Offset
- Producer → Broker → Consumer Group

### 关键设计

| 组件 | 设计要点 |
| :--- | :--- |
| 存储模型 | Append-only log，顺序写磁盘 |
| 分区策略 | 按 key hash 或 round-robin |
| 消费模型 | Consumer Group，每分区一个消费者 |
| 高可用 | 副本机制（Leader-Follower） |
| 消息可靠性 | ACK 级别（0/all） |

## 04 限流系统

**Q：设计一个限流系统。**

**参考答案：**

**算法对比：**

| 算法 | 原理 | 优缺点 |
| :--- | :--- | :--- |
| 固定窗口 | 时间窗口内计数 | 简单，有突刺 |
| 滑动窗口 | 细分时间格 | 平滑，有边界 |
| 令牌桶 | 匀速生成令牌 | 允许突发 |
| 漏桶 | 匀速消费 | 严格匀速 |

**分布式限流：** Redis + Lua 脚本保证原子性

## 05 搜索引擎

**Q：设计一个搜索引擎。**

**参考答案：**

### 核心流程
爬取 → 解析 → 索引 → 检索 → 排序

### 关键技术

| 组件 | 技术 |
| :--- | :--- |
| 爬虫 | 分布式爬取，URL 去重 |
| 索引 | 倒排索引，FST |
| 检索 | BM25 + 向量检索 |
| 排序 | Learning to Rank |
| 架构 | Elasticsearch / 自研 |
