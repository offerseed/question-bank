# 推荐系统设计题

---

## 01 推荐系统

**Q：设计一个大规模推荐系统。**

**参考答案：**

### 需求分析

- 功能：根据用户兴趣推荐内容（视频/商品/新闻）
- 非功能：高 QPS（万级）、低延迟（<200ms）、个性化

### 经典架构：召回 → 排序 → 重排

**1. 召回层**
| 方法 | 特点 |
| :--- | :--- |
| 协同过滤 | 基于用户/物品相似度 |
| 向量召回 | 双塔模型，ANN 检索 |
| 多路召回 | 不同策略并行，融合 |
| 图召回 | GNN 捕获高阶关系 |

**2. 排序层**
| 模型 | 特点 |
| :--- | :--- |
| LR + GBDT | 传统方案 |
| DeepFM | 自动特征交叉 |
| DIN/DIEN | 引入用户行为序列 |
| 多任务模型 | 同时优化点击+完播+互动 |

**3. 重排层**
- 多样性保证（MMR, DPP）
- 业务规则（去重、强插、流量控制）
| -->

### 数据流

```
用户请求 → 特征服务 → 多路召回 → 粗排 → 精排 → 重排 → 返回
                ↑
           特征平台（在线/离线特征）
```

### 关键问题

| 问题 | 解决方案 |
| :--- | :--- |
| 冷启动 | 内容理解、探索利用、默认策略 |
| 特征实时性 | 在线特征服务、流式计算 |
| 模型更新 | 增量训练、A/B 测试 |
| 多目标 | 多任务学习、帕累托优化 |
